# Lint reference

Generated by `ferrosip lint --list --markdown`; see [lint.md](lint.md) for how to run the linter and silence a lint.

## correctness (default: deny)

Almost certainly a bug.

| lint | checks | what |
|---|---|---|
| `infinite_loop` | `.fsr` | `while true` that nothing leaves. The loop has no `break`, `return`, `exit`, `drop` or `await`, so it spins until the engine's loop guard (10000 rounds) stops it and the request is left unanswered. Add a way out. |

## suspicious (default: warn)

Probably a mistake.

| lint | checks | what |
|---|---|---|
| `unused_variable` | `.fsr` | a `let`, `for` or match binding that is never read. A value that is computed and never used is usually a typo or a leftover. If the call is wanted for its effect, keep it and name the variable `_name` (or bind `_` in a match pattern). |
| `unused_function` | `.fsr` | a `fn` that nothing calls. Dead code: remove it, or call it from a route. |
| `unused_flag` | `.fsr` | a `flag` that is never set or tested. Every flag takes one of the 32 message flags. Remove the declaration. |
| `unused_import` | `.fsr` | an `import` of a module the file never calls. Importing a module that is not used makes readers look for it. Remove it from the list. |
| `unused_state` | `.fsr` | a `shared table` or `dialog var` that is never used. A declared table still takes shared memory, and a dialog var is part of every dialog. Remove it. |
| `constant_condition` | `.fsr` | `if`/`guard`/`while` on a literal `true` or `false`. One branch can never run. For a switch you set per deployment, use a `[feature]` in ferrosip.toml (`import { features } from config`); otherwise remove the dead branch. |
| `unreachable_arm` | `.fsr` | a match arm that an earlier arm already covers. Arms are tried in order: one after `_`, or one that repeats an earlier pattern without a guard, never matches. |
| `number_interpolation` | `.fsr` | `{4}` or `{2,3}` inside a string. Braces in a string interpolate: `"[0-9]{4}"` is the text `[0-9]4`, not a regex quantifier. Write `\{4\}` for literal braces (the fix does that). |
| `timer_too_frequent` | `.fsr` | `on timer(every: …)` below 100ms. Each run takes a worker. Timers that fire many times a second rarely need to; poll less often. |
| `unknown_reply_reason` | `.fsr` | `reply(code)` with a code that has no standard reason phrase. Without a reason ferrosip sends the standard phrase for the code; this code has none, so the phrase would be "Unknown". Pass one: `reply(499, "Rejected")`. |
| `record_route_without_loose_route` | `.fsr`, `.cfg` | Record-Route is added, but Route headers are never followed. Record-Route asks the endpoints to send in-dialog requests through this proxy; without `rr.follow()` (.cfg: `loose_route()`) those requests are routed like new ones. |
| `unused_route` | `.cfg` | a `route[NAME]` (or failure/branch/onreply route) that nothing uses. Nothing calls or arms it. Remove it. |
| `unused_feature` | ferrosip.toml, modparam | a `[feature]` value that the routing never reads. Remove it, or read it with `features.name` in the routing. |

## security (default: warn)

Leaves the server open to abuse.

| lint | checks | what |
|---|---|---|
| `missing_max_forwards` | `.fsr`, `.cfg` | requests are relayed without a Max-Forwards check. Without it a request can loop between proxies until something breaks. Start the request route with `guard msg.max_forwards > 0 else reply(TooManyHops)` (.cfg: `mf_process_maxfwd_header(10)`). |
| `register_without_auth` | `.fsr`, `.cfg` | REGISTER is saved, but nothing authenticates. Anyone can register any user and receive their calls. Challenge first (`auth.www_challenge`, `auth.check`…) or limit who may register (permissions). |
| `sql_injection` | `.fsr` | a value interpolated into the text of an `sql.*` query without `sql.quote`. `"… WHERE user = '{msg.ruri.user}'"` puts the value into SQL as it is: a quote in it (legal in a SIP user part) breaks the query or changes what it does. Write `{sql.quote(msg.ruri.user)}` (no quotes around it); numbers may stay as they are. |
| `open_relay` | `.fsr`, `.cfg` | requests are relayed, but no caller is authenticated or checked. Nothing in the routing authenticates callers or checks where requests come from, so anyone can send calls through this proxy (toll fraud). Authenticate, or check `msg.src.ip` / permissions / the dispatcher list before relaying. |
| `plaintext_secret` | ferrosip.toml, modparam | a password or key written in ferrosip.toml. Configuration files end up in repositories and backups. Use `${ENV_VAR}` (or a `*_file` parameter where the module has one). |

## style (default: warn)

Works, but can be simpler.

| lint | checks | what |
|---|---|---|
| `needless_import` | `.fsr` | `import log` / `import txn`. `log` and `txn` are always available; the import does nothing. |
| `bool_comparison` | `.fsr` | comparing with `true` or `false`. `x == true` is `x`, and `x == false` is `!x`. |
| `redundant_reply_reason` | `.fsr` | `reply(code, reason)` with the reason ferrosip would send anyway. `reply(404)` sends "Not Found" by itself. |
| `collapsible_if` | `.fsr` | `if a { if b { … } }` with no else. Write `if a && b { … }`: one level of nesting less. |
| `collapsible_else_if` | `.fsr` | `else { if … }`. Write `else if …`. |
| `empty_block` | `.fsr` | an empty `if` body or `else {}`. Remove the empty branch (or invert the condition). |
| `needless_return` | `.fsr` | `return` as the last statement. The route ends there anyway. |
| `redundant_default` | ferrosip.toml, modparam | a parameter set to its default value. The line does nothing; `ferrosip check --explain` still shows the value. Remove it. |

## pedantic (default: allow)

Opinionated; turn on with `-W pedantic`.

| lint | checks | what |
|---|---|---|
| `table_without_ttl` | `.fsr` | a `shared table` with no `ttl`. Entries stay until removed. Keyed by something callers choose (an IP, a user), the table can grow without bound; add `ttl 10m` unless every key is removed explicitly. |
| `relay_without_timeout` | `.fsr` | `await txn.relay(msg)` without `timeout:`. The wait is then the tm module's default (fr_inv_timer for INVITE). Say how long the route waits. |
| `raw_kamailio` | `.fsr` | `pv("$…")`, `kamailio.call(…)` or a `kamailio.*_route` handler. The escape hatch to Kamailio (what `ferrosip import` writes when there is no typed form) is not checked: a typo in a variable or function name, a wrong argument, a call where it can't run only show at run time. Replace it with the typed form where there is one (`msg.ruri.user` for `$rU`, a `let` for `$var(x)`, `await txn.relay` for a failure_route). |
| `hardcoded_address` | `.fsr` | an IP address written in the routing. Addresses change per deployment. Put it in ferrosip.toml (`[feature] pstn = "sip:10.0.0.9"`) and read it with `features.pstn`. |
