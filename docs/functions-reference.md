Generated by `ferrosip schema --fsr`: do not edit. The language: [fsr.md](fsr.md).

Each function is `namespace.name(…)`; the namespace is the module's ferrosip name.
- `x?` may be left out (`x = v`: `v` when left out), `const` must be written as a constant;
- **returns** `Bool` (a check), `Action` (answers or relays the request: the route ends) or nothing;
- **where**: request processing (`route`), `after await`, `on reply`, event routes (`event`).
